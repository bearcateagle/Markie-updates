# Markie installers

This repository contains Android installers and update metadata only.

[Download the latest installer](../../releases/latest). Open the APK on your phone and choose Update.
Do not uninstall Markie first. Existing Site Walks stay on the phone.

After installing 0.4.27 or later, use **More > App updates** in Markie.
Android may ask you to allow installs from Markie once, then asks you to confirm each update.
Downloads start only when you choose them. No login is needed.

The app source code and Site Walk files are not stored in this repository.
